## English

September 11, 2026 update: the daily list, characters and achievement collections remain. App copy and both introductions have been edited to remove repeated explanations and slogans. The planner asks about the goal and deadline directly, and loading messages describe what the app actually knows.

- Planner instructions are now v1.1.1; companion and achievement-design instructions are v1.0.1. Existing response schemas are unchanged.
- Shared writing rules are included in model requests. Tasks need clear completion criteria, and praise needs supporting records. Plans still require validation and confirmation.
- IPv4 loopback normalization and distinct proxy/upstream errors improve local testing and retries.
- Credentials stay in Keychain or server secrets. Personal endpoint/model settings are excluded from Git; published values are placeholders.

The screenshots above are reused captures of the retained interface. Connection-fix regression passed 46 server, 13 iOS unit and 2 UI tests. Some live generations succeeded, but recent upstream HTTP 504 responses remain unresolved. Seven-day adjustment is not fully verified. This is a development source release, not an App Store binary or a production reliability claim.

This is an update to the existing v1.1.0 release description. Its original source tag stays fixed; the release notes link to the copy-revision commit separately. v1.0.0 is unchanged. ## Local configuration / 本地配置

Create an ignored `.env.local` in the repository root using the variable names from `supabase/.env.example`, and set your own HTTPS endpoint, model and reasoning setting. Keep the key in macOS Keychain using `Scripts/configure-local-ai.sh`, then run `Scripts/run-local-ai-test.sh`. Never upload `.env.local` or keys. Confirm the actual provider before sending personal data.

在仓库根目录创建被 Git 忽略的 `.env.local`，参考 `supabase/.env.example` 填写自己的 HTTPS 接口、模型和思考设置。密钥使用 `Scripts/configure-local-ai.sh` 保存到钥匙串，再运行 `Scripts/run-local-ai-test.sh`。不要上传配置或密钥；发送个人数据前应确认实际服务商。
