## 中文

v1.2.0 将界面中的聊天式标签改为明确的功能名称。新增事项、智能排程、目标管理、公共成就与个人成就采用一致用词；表单仍只默认显示名称和日期，其余设置折叠。

成就册重新整理了名称、条件和隐藏线索。名称参考游戏成就的简短写法，描述直接说明需要完成什么。不复制游戏名称、台词或素材，不展示虚构稀有度。公共成就仍为 24 项，六件装备对应关系、历史记录和已解锁资格不变。

AI 个人成就设计指令升级为 1.0.2，并重新打包到服务端请求中。它要求名称与目标相关，不把完成次数写成实际里程、技能掌握或职业结果；响应结构仍为 1.0.0。已接受的个人定义不会重写，新规则作用于今后的生成提案。更新源码后，运行中的代理需要重新启动或部署才会加载新指令。本轮未进行付费模型联调，不能据本地测试宣称真实输出质量已验收。

## English

v1.2.0 replaces conversational UI labels with consistent product terminology and revises the achievement gallery. Names are shorter and tied to actions; descriptions explain the actual conditions. The 24 public achievements, six equipment mappings, stored records and earned unlocks are unchanged.

Personal achievement-design instructions are now 1.0.2 and are included in the generated server bundle. They distinguish recorded activity from skill mastery, fitness outcomes or career success. The response schema remains 1.0.0. Accepted definitions are not rewritten; the instructions apply to new proposals after the proxy is restarted or redeployed. No paid model evaluation was performed for this revision.

The screenshots above reuse earlier sample-data captures. Some labels differ from v1.2. The app and widget use version 1.2.0, build 3; existing release tags stay fixed. Domain-specific achievements are recommendations, not shipped functionality. See the [product comparison and scope proposal](../PRODUCT-COMPARISON-2026-09.md).

Regression checks passed: 57 Core tests, 15 app unit tests, 3 Chinese UI tests and 48 server tests. These do not validate live model output quality. This is a source release, not an App Store binary. Live AI reliability, seven-day adjustment integration, device permissions, multi-device iCloud and purchase testing remain incomplete. Personal API credentials and endpoint settings are excluded from the repository.
