## 中文

v1.3.0 修正已保存的 AI 个人成就仍显示生造名称的问题。此前更新生成指令只影响新提案，无法改变旧成就页面上的文字。本版在显示时读取已接受的规则，为个人成就使用明确的里程碑名称。

- 首次完成的成就显示“首次完成”；其他成就显示“完成 N 次”“累计记录 N 天”或“达标 N 个周期”。
- 卡片、详情和分享卡使用相同名称。条件注明完成天数不要求连续，周期条件按实际保存的周期长度显示。
- 原始 AI 名称和说明保留在详情的“AI 原始文案”折叠项中。隐藏成就未解锁时，名称、条件及数字进度继续保密。
- 缺失或无效的规则显示“成就条件暂不可用”，不承诺正在同步或即将恢复。

这次只改显示，不重写数据库中的名称、规则、版本或解锁记录。已有进度和已获资格保留，无需删除或重新生成个人成就。24 项公共成就、装备对应关系、动画与模型配置没有变化。

应用与小组件版本为 1.3.0，构建号 4。v1.0.0、v1.1.0 和 v1.2.0 标签保留。README 沿用此前公开的示例数据截图；本次用现有记录核对过个人成就页面，但不上传含个人记录的截图。

验证：19 项 App 单元测试、1 项成就册界面测试通过，覆盖显示名称、单位、规则不变、隐藏信息保护及无效规则提示。本轮没有重跑完整 Core / 服务端回归，也没有调用付费模型。版本仍是开发原型的源码发布，不含 App Store 安装包；此前记录的 AI 上游超时等限制未在本版解决。

## English

v1.3.0 fixes awkward names still displayed by previously saved AI personal achievements. Earlier prompt updates affected new proposals only. The app now derives the displayed milestone from each accepted rule.

Cards, details and share previews use consistent Chinese labels for first completion, completion counts, distinct activity days and qualifying cycles. Conditions state that activity days need not be consecutive and use the saved cycle length. Original AI names and descriptions remain in a collapsed detail section. Hidden achievements keep their names, conditions and numeric progress concealed until unlocked. Missing or invalid rules show an unavailable message rather than claiming a sync is in progress.

This is a presentation change. Stored names, rules, versions, progress and earned unlocks are preserved; regeneration is not required. The 24 public achievements, equipment mappings, animations and model configuration are unchanged.

The app and widget use version 1.3.0, build 4. Earlier release tags remain fixed. Existing public sample-data screenshots are reused in the README; screenshots containing personal records are not included.

Verification passed: 19 app unit tests and one achievement-collection UI test. The full Core and server suites were not rerun, and no paid model request was made for this release. This remains a prototype source release, not an App Store binary. Previously documented upstream AI timeouts and other integration limitations remain unresolved.
